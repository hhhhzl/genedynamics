# Code of conduct

We want project spaces to support careful technical disagreement and productive
collaboration.

Participants must:

- treat others with respect and avoid harassment, intimidation, and personal
  attacks;
- critique ideas, evidence, code, and experimental design without demeaning the
  person presenting them;
- disclose relevant conflicts and give credit for research, code, data, and
  review work;
- avoid publishing private information, credentials, unsafe robot access
  details, or embargoed vulnerability information;
- accept maintainer decisions about scope, safety, and release quality while
  remaining free to disagree constructively.

Maintainers may edit or remove content, reject contributions, or restrict
participation when behavior violates these expectations. Report conduct issues
privately through the repository's maintainer contact or GitHub reporting
mechanism. Maintainers will protect reporter privacy as far as practical and
will not tolerate retaliation.

This policy applies in repository discussions, reviews, project communication,
events, and public representation of the project.
