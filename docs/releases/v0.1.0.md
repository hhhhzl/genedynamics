# GenerativeDynamics v0.1.0

First open-source prerelease of **Generative dynamics on manifold**, a modular
framework for robotics planning, control and learning.

## Included

- MDOC, MD-COAS, 2GO and MGA, alongside the configured planners and baselines.
- Six task families: planar navigation, D3IL arm avoidance, quadruped stepping
  stones, humanoid corridors, peg insertion and surface scanning.
- Generative candidate batches with supported CBF/CFS corrections, constraint
  geometry and manifold refinement; policy priors and learned diffusion integrations.
- Python environment/planner composition, YAML experiments, resumable seed
  matrices, metrics, trajectory artifacts and deployment interfaces.
- Original paper demonstration gallery, architecture and user documentation.
- CPU/GPU Python examples, batched constraints, and local CPU/NVIDIA Docker workflows.
- MIT for framework code, with complete bundled third-party license notices.

## Status and limitations

This is an alpha release. The [validation record](https://github.com/hhhhzl/genedynamics/blob/v0.1.0/docs/releases/v1_evidence.md) distinguishes
executed checks from unqualified paths. GPU recipes require an NVIDIA host;
GPU parity and performance have not been qualified in this release. MGA GPU
and humanoid walking/push readiness remain deferred. Torch integrations have
separate dependencies and checkpoints; Torch is not yet a shared planner backend.

Soft-robot, co-design and 3DGS research are absent from the V1 source and
release packages. Existing repository history is retained.

Hardware timing, memory, safety and repeated-run reliability need measurements
under the [metrics contract](https://github.com/hhhhzl/genedynamics/blob/v0.1.0/docs/reference/metrics.md). Demonstration videos
are not performance evidence.

## Distribution

The GitHub prerelease includes a Python wheel, source archive and SHA-256
checksums. Install the wheel locally with `python -m pip install PATH_TO_WHEEL`.
Task configurations and examples are available in the repository checkout.
A GitHub Release does not imply a PyPI package or published container image.
