# Play2Perfect solver

This package owns Play2Perfect policy inference. It verifies the pinned
upstream checkout, builds the original `rl-games` network, and loads the
published checkpoint. Isaac Sim environment setup and task adaptation remain
outside the solver package.

Upstream source: `kushal2000/play2perfect`, commit
`ff2fc62873f6c6cd93164123c8358e9ce2d65c9b` (see
`requirements/baselines/sources.lock.json`).
